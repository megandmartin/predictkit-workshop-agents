# Build Prediction Ui

Use a single self-contained HTML file unless the approved memo says otherwise. Keep the exact market question and simulation status visible. Include labeled probability input, history, explicit close, manual YES/NO/VOID, Brier scoring, and reset. Enforce state in logic, validate restored local state, escape user text, avoid remote dependencies, and support narrow screens and keyboard focus. Report source-inspection and browser-execution results separately.

## Handoff
Write concrete findings and the smallest next verification. Keep simulation, live provider, chain, deployment, and participant outcomes at distinct evidence levels.
