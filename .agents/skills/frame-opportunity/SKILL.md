# Frame Opportunity

Compare the user problem, current workaround, smallest useful forecast, evidence gaps, Solana rationale, and proposed experiment. Resolve conflicting discovery claims explicitly. Set a build scope, hard cuts, shared contract, acceptance criteria, and named output owners. Treat approval of a local simulation as limited to that scope; no spending, wallet action, release, or submission follows from it.

## Handoff
Write concrete findings and the smallest next verification. Keep simulation, live provider, chain, deployment, and participant outcomes at distinct evidence levels.
