# Continue a workshop sprint

Use when a participant returns after the session. Read the frozen brief, approved memo, completed artifacts, `qa/review.md`, and actual test notes under `runs/<slug>/`. Do not assume an earlier conversation, participant approval, provider response, or browser result still applies without durable evidence.

## Choose one bounded improvement
Reproduce the most consequential known defect or missing proof. Select one observable acceptance criterion, name the owning role and files, make the smallest coherent change, then rerun affected checks. Record what passed and what remains unknown. Revisit current provider, network, contest, or dependency facts before external effects.

## Handoff
Write a clean next-session note with current scope, changed files, exact checks and results, remaining blocker, and next action. Do not silently change the frozen question or treat old approval as permission for spending, publication, wallet use, or submission. This skill is instruction text, not an executor.
