# Select Solana Adapter

Start with the off-chain user journey. State what a chain could add: shared records, attestations, transparency, or execution. Specify proposed adapter inputs, outputs, authority, idempotency, failure and read-back behavior. List exact missing SDK, network, wallet, program, and provider checks. A transaction signature alone does not prove intended state; require observed read-back and negative authorization tests before calling a flow connected.

## Handoff
Write concrete findings and the smallest next verification. Keep simulation, live provider, chain, deployment, and participant outcomes at distinct evidence levels.
