# Run Workshop

Begin with a frozen brief and explain that these Markdown files guide a coding assistant; they do not run eight agents automatically. Run discovery, stop for human review of the chief memo, then build and review. Let participants work in their own projects or ignored runs/ directories. Keep local prototype, live AI, chain, deployment, and user-outcome proof separate. Record actual checks and follow-up actions. See WORKSHOP.md.

## Handoff
Write concrete findings and the smallest next verification. Keep simulation, live provider, chain, deployment, and participant outcomes at distinct evidence levels.
